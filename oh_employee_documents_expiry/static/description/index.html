Open HRMS Employee Documents Expiry provides comprehensive document lifecycle management for employee certifications, visas, passports, medical records, and contracts. It automatically triggers advance warning emails to employees and schedules reminder tasks for managers before documents lapse, preventing regulatory non-compliance.

You can customize notification rules per document type with 4 options: (1) Notification on expiry date, (2) Notification before few days (on expiry date and a designated number of days in advance), (3) Everyday till expiry date (daily reminders starting from a specified number of days before expiry), or (4) Notification on and after expiry (daily notices starting on the expiry date for a specified number of days).

An automated background process runs daily. When a document matches its configured notification timing, the system sends an email directly to the employee's registered work email address. Simultaneously, it creates a To-Do activity scheduled for the employee's direct manager with the document expiry deadline.

Yes! In addition to automated daily notifications, administrators can click the manual reminder button directly on any document record to send an immediate alert email to the employee whenever necessary.

When a document expires or needs renewal, click the "Renew" button on the form. A guided renewal wizard opens where you enter the new issue date, new expiry date, upload updated document attachments, and provide a mandatory renewal reason. Confirming the wizard reactivates the document while preserving past records.

Yes, completely. The renewal wizard automatically archives the prior issue date, previous expiry date, past attachments, responsible user, and renewal reason into a dedicated Renewal History tab, alongside an immutable audit note in the chatter.

No. The system enforces a validation rule preventing duplicate active documents of the same type for any individual employee. Users are guided to renew the existing document instead of creating conflicting active duplicates.
