Biometric Device Configuration

Navigate to Attendances → Biometric Device → Biometric Device. Configure the device name, IP address, port number, communication password, and company.

Test Connection with Biometric Device

Click the "Test Connection" button to verify real-time communication between Odoo and your biometric terminal. A "Successfully Connected" alert confirms active connectivity.

Download Attendance Data & Fetch Device Information

Click "Download Data" to pull attendance logs into Odoo. Device specifications such as firmware version, serial number, platform, and MAC ID are automatically retrieved and displayed.

Clear Attendance Logs from Device

Click "Clear Data" to safely purge stored attendance records from the physical device memory once downloaded, preventing storage overflow and duplicates.

Remote Device Restart

Easily reboot the biometric terminal remotely from the Odoo backend interface with a built-in safety confirmation modal.

Real-Time Live Attendance Capture

Enable "Live Capture" to automatically stream and record employee punches from the biometric device into Odoo in real time with an active status stopwatch timer.

Synchronize Device Clock Time

Click "Set Time" to automatically calibrate and match the biometric device's internal clock with your current Odoo server timezone for exact attendance timestamps.

Biometric User Management Wizard

Open the User Management wizard to fetch all enrolled users from the device, register new employees, update details, or delete users directly from Odoo.

Open HRMS Biometric Device Integration connects ZKTeco biometric attendance terminals (supporting facial recognition and fingerprint recognition) directly with Odoo 20 HR Attendance. It automates log downloads, supports real-time live capture, and provides complete user management from Odoo.

The module supports standalone ZKTeco devices that communicate over network TCP/UDP using the standard ZK protocol, including uFace 202, iFace 990, K40 Pro, SFace 900, FR1500, UA760, MB10, and other compatible models.

When Live Capture is enabled, Odoo starts a background listening thread that captures punches from the device as employees check in or out. The attendance logs are immediately processed into Odoo HR Attendance, with an active stopwatch timer displayed on the device view.

Yes. In Attendance → Configuration → Settings, enable Schedule Downloads and set the desired interval number and period (Hours or Days). An automated cron job will fetch attendance records periodically in the background.

This module requires the pyzk Python library. You can install it on your Odoo server environment using the command: pip3 install pyzk.

Yes. Through the User Management action on the biometric device form and the employee profile wizard, you can fetch all registered device users, enroll new employees, update user details, or delete users directly from Odoo.

The module includes verification logic based on employee ID, device ID, and punch timestamp to eliminate duplicate check-in/out records, ensuring clean and accurate attendance data in Odoo.
