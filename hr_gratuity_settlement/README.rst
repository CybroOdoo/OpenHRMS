Open HRMS Gratuity Settlement
=============================
Employee Gratuity Settlement during Resignation.

Key Features
------------

* Provides an option to create gratuity settlements for employees during resignation.

* Calculates gratuity amounts based on employee service duration and salary.

* Supports different employment contract types: Limited and Unlimited.

* Supports monthly and hourly wage types.

* Allows configuration of gratuity rules based on service duration.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
