Open HRMS Resignation
======================
This module helps to create and manage resignation requests of the employees.

Key Features
------------

* Multi-Level Approvals.
* Automate departmental clearance checklists and generate comprehensive full & final settlement payslips seamlessly.
* Integrated survey system to effortlessly gather and analyze valuable employee feedback during the offboarding process.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
