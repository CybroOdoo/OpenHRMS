Open HRMS Loan Management
===========================
This module facilitates the creation and management of employee loan requests.

Key Features
------------

* Employees can easily create and track their loan requests.
* Managers and Finance Managers can seamlessly review and approve loan requests.
* Support for early settlements, deferring installments, and loan top-ups.
* Pending installments are automatically deducted during payroll processing.
* Automatic email notifications keep employees informed about their loan request status.
* Real-time Balance Tracking

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
